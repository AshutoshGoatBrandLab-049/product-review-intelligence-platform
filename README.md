
# Product Review Intelligence Platform

AI-powered Product Review Intelligence & Decision-Making Platform.

The platform analyzes customer reviews collected from Flipkart and Myntra and converts raw review data into product health scores, customer insights, root-cause analysis, trends, and actionable business recommendations.

## Platforms

- Flipkart
- Myntra

## Core Pipeline

Reviews
→ Processing
→ Sentiment & Theme Analysis
→ Product Health Scoring
→ Root Cause Analysis
→ AI Recommendations
→ Dashboard

## Project Structure

- `backend` — Backend API and intelligence services
- `frontend` — Product intelligence dashboard
- `docs` — Architecture, database, and API documentation
