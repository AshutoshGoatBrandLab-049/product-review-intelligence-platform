  request.platform,

**Behavior:**

## IMPACT ASSESSMENT

**Current Behavior:**
- User asks question → System checks cache
- If cached within 30 days → Return old answer (NO database query)
- If not cached → Generate fresh answer → Cache it → Return

**Problem:**
- Database changes between identical questions
- Cached answer doesn't reflect new data
- User gets stale information
- Violates "database is source of truth" requirement

**Affected Response Types:**
1. Latest-10 average rating
2. Semantic planner responses (analysis, comparisons, trends)
3. Explain previous responses
4. Retrieval responses

**All response types can return stale data if cached**
